# 主题皮肤开发文档

本系统（导航门户，纯 PHP + MySQL）支持以 **单个 CSS 文件** 的方式扩展主题皮肤，无需修改任何 PHP 代码。皮肤放入 `assets/themes/` 目录后自动被系统识别，经后台「主题皮肤管理」设置可见性后，用户即可在 `/theme.html` 页面切换使用。

- 皮肤注册中心：`includes/themes.php`
- 皮肤目录：`assets/themes/`
- 用户切换页：`/theme.html`
- 后台管理页：`/admin/themes.html`（权限：`manage_themes`）

---

## 一、快速开始

1. 在 `assets/themes/` 下新建文件，如 `ocean.css`。
2. 按下面的格式写入**文件头注释**（元信息）与一个最小皮肤：

```css
/*
Theme Id: ocean
Theme Name: 海洋蓝
Author: 你的名字
Version: 1.0
Description: 深邃如海的蓝色主题。
Dark: no
*/
:root[data-theme="ocean"] {
  --primary: #0284c7;
  --primary-dark: #0369a1;
  --primary-soft: #e0f2fe;
}
```

3. 保存后访问后台「主题皮肤管理」，即可在列表中看到该皮肤（默认对用户可见）。
4. 打开 `/theme.html`，点击「使用此皮肤」即可预览效果。

> 皮肤只在被启用（可见）时才出现在用户切换页；后台列表始终能看到全部已安装皮肤。

---

## 二、文件头注释字段规范

文件**开头必须是一段块注释**，每行一个字段，格式为 `字段名: 值`。字段全部可选，但建议至少提供 `Theme Id` 与 `Theme Name`。

| 字段 | 必填 | 说明 |
|---|---|---|
| `Theme Id` | 是 | 皮肤唯一标识，规则见第四节。缺失时用文件名（去 `.css`）。 |
| `Theme Name` | 是 | 显示名称，如「海洋蓝」。缺失时用 Theme Id。 |
| `Author` | 否 | 作者名，展示在后台管理表。 |
| `Version` | 否 | 版本号字符串，如 `1.0`、`2.3.1`。 |
| `Description` | 否 | 一句话描述，展示在切换卡片与后台。 |
| `Dark` | 否 | `yes` / `no`（默认 no）。标记为暗色皮肤，切换页显示暗色标签。 |

字段解析对大小写、冒号后空格不敏感；编码请使用 **UTF-8（无 BOM）**。

## 三、CSS 变量清单

皮肤通过覆盖 `:root[data-theme="<Theme Id>"]` 下的 CSS 变量生效。**至少应覆盖主色三件套**（`--primary`、`--primary-dark`、`--primary-soft`）；其余变量按需覆盖。

### 1. 品牌主色

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--primary` | `#2563eb` | 主色：按钮、链接、选中态、开关、进度等 |
| `--primary-dark` | `#1d4ed8` | 主色加深：按钮悬浮、标题强调 |
| `--primary-soft` | `#eef2ff` | 主色浅底：激活菜单、当前项背景、标签 |

### 2. 文字与背景

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--bg` | `#f2f4f8` | 页面整体底色 |
| `--card` | `#ffffff` | 卡片 / 表格 / 弹层背景 |
| `--topbar-bg` | `#ffffff` | 顶部导航栏背景 |
| `--text` | `#1f2937` | 正文文字 |
| `--muted` | `#6b7280` | 次要文字、提示、占位符 |
| `--border` | `#e5e7eb` | 分割线、控件描边 |

### 3. 表面色（层级背景）

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--surface-1` | `#f8fafc` | 极浅底：表头、只读行、提示条 |
| `--surface-2` | `#f3f4f6` | 浅底：悬浮态、禁用控件、代码块 |

### 4. 语义色

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--success` | `#16a34a` | 成功提示、启用状态 |
| `--danger` | `#dc2626` | 危险操作、删除、错误提示 |

### 5. 圆角、阴影与尺寸（一般无需改动）

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--control-radius` | `8px` | 输入控件圆角 |
| `--radius-card` | `10px` | 卡片圆角 |
| `--shadow-xs` | `0 1px 2px rgba(16,24,40,.04)` | 轻阴影 |
| `--shadow-card` | `0 1px 2px rgba(16,24,40,.04), 0 1px 3px rgba(16,24,40,.07)` | 卡片阴影 |
| `--topbar-h` | `57px` | 顶部栏高度 |
| `--side-w` | `212px` | 后台侧边栏宽度 |

> 除变量外，你也可以在皮肤文件中写任意 CSS 覆盖具体组件（内置皮肤即对聚焦光晕、表格行 hover 等做了微调）。建议只追加、不删除原有样式，避免破坏布局。

---

## 四、Theme Id 命名规则

- 仅允许：字母、数字、下划线 `_`、连字符 `-`
- 长度：2 ~ 40 个字符
- 建议：全小写、用连字符分词，如 `ocean-blue`、`forest-green`
- **`default` 为保留 ID**（经典蓝内置皮肤，无独立文件），不可占用。
- 自定义皮肤 ID 若与内置皮肤（`violet`、`emerald`、`rose`、`amber`、`cyan`、`dark`）重复，**内置皮肤优先**，自定义文件不会被加载。要替换内置皮肤，请先取一个不同的 ID。

---

## 五、暗色皮肤要点

将文件头的 `Dark` 设为 `yes`，并覆盖表面色变量，使整体进入深色方案。可参考内置 `assets/themes/dark.css`，一个完整暗色皮肤至少需要：

```css
/*
Theme Id: midnight
Theme Name: 午夜
Dark: yes
*/
:root[data-theme="midnight"] {
  color-scheme: dark;                 /* 让滚动条、表单原生控件跟随深色 */
  --bg: #0b1220;
  --card: #111c2e;
  --topbar-bg: #111c2e;
  --text: #dbe4f0;
  --muted: #8b9bb4;
  --border: #243248;
  --surface-1: #16233a;
  --surface-2: #1d2c47;
  --primary: #4f8cff;
  --primary-dark: #8ab4ff;
  --primary-soft: #173158;
}
```

暗色模式下请额外检查以下组件（内置 dark.css 均有覆盖，可直接对照）：

- 输入框 / 下拉框 / 文本域背景与文字色
- 表格表头粘底粘头、行悬浮色
- 按钮次级样式（`.btn-mini`）
- 权限矩阵与权限规则卡片（`.perm-matrix`、`.perm-rules-card`、`.delegate-item`）
- 代码块 / CSV 模板（`.csv-template`）
- 可折叠卡片（`.rule-card`、`.create-box`、`.probe-card`）
- 弹窗内联编辑行（`.edit-row`）
- 各类提示标签（`.pill-self`、`.own-grp-tag` 等）

文字与背景的对比度建议满足 WCAG AA（正文不低于 4.5:1）。

## 六、可见性、默认皮肤与权限机制

- **可见性**：后台「主题皮肤管理」可对每个皮肤执行「显示 / 隐藏」。只有可见皮肤出现在 `/theme.html`；`default` 始终可见。
- **可见用户组**：后台还可把皮肤限定为仅对指定用户组可见（全不选 = 所有用户及游客可见；勾选后仅勾选组成员可见）。该限制与「显示 / 隐藏」同时生效；`default` 不受此限。
- **站点默认皮肤**：后台可将任一可见皮肤设为默认；未自行选择皮肤的用户跟随该默认。若默认皮肤被隐藏，系统自动回退到 `default`。
- **用户选择的优先级**：
  1. 用户在账号内选定的皮肤（`users.theme`）
  2. 浏览器 cookie（未登录或访客）
  3. 站点默认皮肤（`settings.theme_default`）
  4. `default`
- **顶部入口开关**：后台「站点设置」中的「顶部显示主题入口」控制顶栏是否出现「🎨 主题」链接（至少有 2 套可见皮肤时才展示）。
- **管理权限**：`manage_themes`（可见性 / 默认皮肤）与 `manage_theme_meta`（皮肤名称/版本/作者/暗色类型/可见用户组等元数据）均可由系统管理员组在权限矩阵分配、授予普通管理员组，且**支持二级授权**（与其他权限一致，受级别与范围约束）。

### 元数据后台覆盖（无需改文件）

- 后台「主题皮肤管理 → 编辑元数据」可直接修改皮肤的**显示名称、版本、作者、说明、暗色类型、可见用户组**，覆盖值存入数据库 `theme_overrides` 表，不修改 CSS 文件。
- 覆盖字段留空时回退到本文件注释头（自定义皮肤）或内置注册值；「暗色类型」选择「跟随原始」即不覆盖；勾选「恢复原始元数据」会删除该皮肤的全部覆盖记录。
- 这意味着：分发皮肤时在注释头写好默认元信息即可，站点管理员后续可自行本地化（如改名、改版本号），升级皮肤文件不会丢失其覆盖值。

## 七、调试方法

1. **强制刷新**：皮肤 CSS 链接带有 `filemtime` 版本号，正常保存即自动破缓存；如仍不生效，请强制刷新（Ctrl + F5）或在宝塔重启 PHP-FPM 以清理 OPcache。
2. **查看当前皮肤**：`<html>` 标签上带有 `data-theme="<id>"` 属性，可在浏览器开发者工具的 Elements 面板确认。
3. **临时调试**：在开发者工具 Console 中执行
   `document.documentElement.setAttribute('data-theme','ocean')`
   可即时切换（不写库），便于对比变量效果。
4. **变量检查**：Elements → Styles 面板选中 `<html>`，可查看 `:root[data-theme="..."]` 下所有变量的实际计算值；Computed 面板可查任意元素的变量解析结果。
5. **未被识别时排查**：
   - 文件是否在 `assets/themes/` 且扩展名为 `.css`
   - 文件头块注释是否在文件最前面
   - `Theme Id` 是否符合命名规则、是否与内置皮肤冲突
   - 后台该皮肤是否被「隐藏」

---

## 八、分发自定义皮肤

皮肤是**自包含的单文件**：将 `<your-theme>.css` 交给其他站长放入其站点的 `assets/themes/` 目录即可使用。若皮肤引用了图片/字体等额外资源：

- 请使用**完整 URL** 或相对皮肤文件可寻址的路径，并随皮肤一并打包；
- 不要引用系统其他内部文件路径，升级时可能变化。

建议在文件头注释中保持 `Author`、`Version`、`Description` 信息完整，便于后台识别与后续更新。
